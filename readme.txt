COMO USAR
1. Abra index.html para ver a loja.
2. Clique em uma camisa: abre produto.html com tamanho, personalização e tabela de medidas separada.
3. Carrinho calcula o total e envia o pedido para o WhatsApp 12 99158-0761.
4. Painel: admin.html. Senha inicial 1234.
5. No painel você pode adicionar fotos da galeria, alterar nome/categoria/modelo/preço, excluir/adicionar produtos e trocar banners.
6. As alterações do painel usam localStorage deste navegador. Para um painel realmente online e sincronizado entre celulares/computadores, será necessário conectar a um backend/Firestore/Supabase depois.
